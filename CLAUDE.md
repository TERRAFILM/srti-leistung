
# Flujo de trabajo (2 Macs: Pro + Air)

Este proyecto se sincroniza por Git entre dos Macs. iCloud NO sincroniza el codigo.

**IMPORTANTE: este repo usa la rama `principal`, NO `main`.**

**Al iniciar una sesion:** ejecuta `git pull origin principal` para traer lo ultimo de GitHub.

**Al terminar:** ejecuta `git add .`, luego `git commit -m "<resumen>"`, y luego `git push origin principal`.

Haz esto de forma proactiva sin que el usuario lo pida.
